# KubeOnCall 节点告警策略 MVP

> 状态：已于 2026-07-16 完成当前范围验收。运行时加载 5 条 `node-mvp` 策略，NodeDown 真实链路、基础诊断摘要和通知调用均已通过。

## 1. 目标与边界

本模块只服务于一台或少量 Kubernetes 节点的基础监控闭环，与《告警上层接入.md》使用同一范围：Prometheus 判断节点指标，Alertmanager 转发，KubeOnCall 根据显式策略记录、做简单诊断并通知。

本轮不建设通用策略治理平台，也不以策略驱动工单、审批、RAG、记忆、自动修复或复杂告警运营。

## 2. 当前启用策略

运行时默认加载 `src/main/resources/alarm-policies-node-mvp.yml`，只包含以下五条策略：

| 告警名 | 条件 | 等级 | 持续时间 | 说明 |
| --- | --- | --- | --- | --- |
| `NodeDown` | `up{job="node-exporter"} == 0` | P1 | 2 分钟 | Node Exporter 不可抓取 |
| `NodeCPUHigh` | CPU 使用率 > 85% | P2 | 5 分钟 | 节点 CPU 持续高 |
| `NodeMemoryLow` | 可用内存 < 15% | P2 | 5 分钟 | 节点内存不足 |
| `NodeDiskHigh` | 文件系统使用率 > 85% | P2 | 5 分钟 | 节点磁盘空间不足 |
| `NodeInodeHigh` | inode 使用率 > 85% | P2 | 5 分钟 | 节点小文件容量不足 |

`NodeNotReady` 不默认启用。只有部署 kube-state-metrics 并确认其指标可抓取后，才新增该规则及对应策略；它不能由 Node Exporter 替代。

`src/main/resources/alarm-policies.yml` 中的全量策略目录保留作历史参考和回归测试，不作为当前运行时策略源。

## 3. 最小策略处理规则

1. 只按 `alertName`、节点资源类型和必要指标匹配策略。
2. Prometheus 已做阈值判断时，Alertmanager Webhook 未带数值也可按完全匹配的告警名进入对应策略。
3. 使用现有 fingerprint 做基础去重；不增加跨节点聚合、根因关联、复杂抑制或灰度规则。
4. 恢复事件只按 Alertmanager `RESOLVED` 记录，不增加人工恢复确认、复盘或外部工单要求。
5. 所有策略均 `autoSilence: false`，不触发自动静默或自动修复。

## 4. 最小工作流

五条节点策略都使用 `node-mvp` 模板：

```text
deviceInfoNode -> stateCompareNode       （可选诊断，失败可降级）
resultPushNode -> notificationNode       （记录与通知主路径，不依赖外部诊断 adapter）
```

它只尝试采集基础节点信息、回查指标，并保证记录诊断摘要和通知主路径不被外部诊断 adapter 故障阻断。RAG、记忆、工单、审批、静默和自动处置不会进入该模板，也不是告警成功接收的前置条件。

## 5. 验收

1. KubeOnCall 启动日志显示加载 5 条 `node-mvp` 策略。
2. Prometheus 的五条规则分别可以映射到同名 KubeOnCall 策略。
3. 一条 CPU 或磁盘告警经 Alertmanager 转发后，KubeOnCall 返回 `202`，生成记录、基础诊断摘要和通知。
4. 重复告警不会重复执行完整工作流；`RESOLVED` 可被记录。
5. Node Exporter、Prometheus 规则和 Alertmanager receiver 通过实际 Docker 演练后，本模块即完成。

## 6. 明确延期或删除

- P0/P1 双阈值策略、独立值班 receiver、复杂 inhibition/silence。
- 策略版本、灰度、回放、审批发布、Prometheus 自动发布、checksum 与原子回滚。
- 多集群/多环境覆盖、变更关联、告警健康度、噪声统计和周报。
- Blackbox HTTP/TCP/DNS、服务 SLO、Burn Rate、控制面、Pod、Deployment 等非节点策略。
- PagerDuty/Jira/ServiceNow、工单、审批、RAG、记忆和自动处置。

未来有明确生产需求时，再将某一项独立立项；不得作为当前节点监控 MVP 的待办或验收条件。
